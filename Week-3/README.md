## Overview
This project demonstrates exploratory data analysis (EDA), descriptive statistics, correlation analysis, and visualization for a hypothetical logistics operation.

## Dataset
`logistics_week3_dataset.csv` contains 180 simulated shipment records covering distance, shipment volume, traffic, vehicle type, weather, delivery time, transportation cost, and delay.

## Files
- `Week_3_Logistics_Advanced_Data_Analysis_Report.docx` — final report
- `week3_visualization.py` — Python EDA and visualization script
- `logistics_week3_dataset.csv` — simulated dataset
- `visualizations/` — generated charts

## Key Results
- Average delivery time: 119.12 minutes
- Median delivery time: 118.50 minutes
- Average transportation cost: 194.84
- Average shipment volume: 114.30 units
- On-time delivery rate: 31.11%

## Run
Install dependencies with `pip install pandas numpy matplotlib`, then run `python week3_visualization.py`.

## Note
The dataset and results are simulated for educational/internship purposes and do not represent real company performance.
