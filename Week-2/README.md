## Project Overview
This project demonstrates a logistics data-preprocessing pipeline using Python. The raw simulated dataset intentionally contains missing values and duplicate records so that realistic cleaning methods can be demonstrated.

## Methods
- Dataset inspection
- Missing-value detection and treatment
- Duplicate removal
- Date conversion
- Delivery-time feature engineering
- IQR-based outlier detection
- One-hot encoding
- Min-Max normalization

## Files
- `Week_2_Data_Preprocessing_Report.docx` - final report
- `week2_preprocessing.py` - complete preprocessing script
- `logistics_week2_raw_dataset.csv` - raw simulated dataset

Running the Python script creates `logistics_week2_cleaned_dataset.csv`.

## Note
The dataset is simulated for educational/internship purposes and does not represent real company data.
